# v1.0.0 — 睡前听 首个正式版本

## 主要内容

**把「发现」做成主功能**：聚合本周热门视频 / 音乐 / 有声内容，分类浏览，一键直达对应 App，
一键把音频缓存到本地。原来的链接解析功能降为副功能保留。

## 新增

- **发现页（主功能）**
  - 分类：精选 / 视频 / 音乐 / 听书 / 知识
  - 多榜单交叉聚合，30 分钟缓存，断网可读
  - 新闻流式卡片：封面、时长、作者、播放量
  - 下拉刷新
  - 卡片点击 → 详情页；「去收听」通过 `ACTION_VIEW` 拉起对应 App
- **推荐详情页**：大封面、标题、简介、来源、播放量、时长，底部双按钮（缓存音频 / 去 App 收听）
- **编辑精选兜底**：接口不可用时加载内置 26 条精选，首页永不白屏
- **历史记录**：每次解析记录状态（已解析 / 已下载 / 失败），可一键重新解析
- **黑夜 / 白天模式切换**：一键切换，状态栏、卡片、插画全部跟随，偏好持久化
- **空状态插画**：曲库为空、历史为空各有明暗两版插画
- **HLS 支持**：m3u8 播放列表合并为单文件后再抽音轨（支持 AES-128 解密）
- **通用网页解析**：任意公开媒体直链的网页也能解析
- **有声/音频平台解析**：免费单集可直接取音频地址

## 改进

- 全新 Q 版矢量图标（纯 XML，约 10 KB，任意分辨率不糊，可主题染色）
- 新应用图标：红渐变 + 白色耳机 + 弯月
- 深色/浅色双色板，View 自动跟随系统主题
- 播放服务支持拖动定位，进度每秒广播
- 解析/下载错误提示全部中文化
- 修复：JSON `null` 被当作字符串导致付费内容误判可下载
- 修复：矢量图标弧线参数非法导致主题切换崩溃

## 安装

1. 下载 `AutoAudio-1.0.apk`
2. 允许「安装未知来源应用」
3. 打开 APK 安装

系统要求：Android 8.0（API 26）及以上。

## 说明

- 仅处理公开免费内容，付费 / 会员 / 充电专属内容会明确提示无法获取，不做绕过
- 无账号体系，数据仅保存在本机，卸载即清空
- 发现页数据来自公开榜单接口，接口变动后可能需要更新解析逻辑
